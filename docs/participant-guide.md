$ npm install -g @testmuai/kane-cli

Then try one example from the docs ↗. Ten minutes now saves you an hour on day one. Most of your credits go
to building your suite; running tests is free after the first run since they cache and replay at zero cost.
Step 3: Build
The brief: build a working web app with any AI coding agent (Claude Code, Cursor, Copilot, Codex, Windsurf,
Kiro, your own MCP setup), use Kane CLI to verify it works, and ship by the deadline.
Solo or teams of up to four
Your repo must be initialized on or after 19 August. We check commit history.
Kane CLI is the only required dependency. Any framework, any stack.
Judges score four things, weighted equally:
Ships: a working app with a real flow that runs end to end
Verified: Kane CLI actually exercised the app and caught or confirmed something meaningful
Closed loop: agent built, Kane verified, result fed back to the agent. The tighter the loop, the higher the
score.
Craft: did you reach for something interesting?

Step 4: Submit before 21 August, 11:59 PM IST
One form: surveymonkey.com/r/kane-cli-hackathon-submission ↗
Have these four things ready:
GitHub repo: public (or invited access for judges), with a README that includes setup steps
Demo video: 3 minutes max. Judges stop watching at 3:00, so lead with the good part. YouTube Unlisted
(not Private) or a Drive link set to "anyone with the link can view." Test your link in an incognito window before
submitting.
One paragraph: what you built, who it's for, which agent you used, and what Kane verifies
Live URL or install command: judges should be able to see it working in under 30 seconds
Submissions lock at the deadline. No pushes after.
